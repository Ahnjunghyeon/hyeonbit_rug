# 현빗 러그

바탕화면에 러그를 깔고, 잡아 옮기거나 검기로 잘라볼 수 있는 Windows 앱입니다.

바탕화면에 러그를 덮어두는 아이디어가 재미있어서 시작했습니다. 여기에 귀멸의 칼날에서 영감을 받은 검술 이펙트를 더했습니다. 업무하다 잠깐 쉬고 싶을 때 러그를 이리저리 끌어보거나, 마음에 드는 호흡으로 잘라보세요.

## 이런 걸 할 수 있습니다

- 러그를 잡아 옮기고 접을 수 있습니다.
- 마우스로 선을 그어 러그를 자를 수 있습니다. 완전히 분리된 조각은 따로 움직입니다.
- 물, 불, 안개, 번개 등 여러 검술 이펙트를 선택할 수 있습니다.
- 네즈코, 탄지로, 젠이츠, 이노스케, 키부츠지 무잔, 기존 러그 중에서 디자인을 고를 수 있습니다.
- 직접 준비한 PNG나 WebP 이미지도 러그로 사용할 수 있습니다.
- 러그를 표시할 모니터와 창 위·아래 배치를 설정할 수 있습니다.

환경설정은 변경하는 즉시 저장됩니다.

## 소스로 실행하기

Windows에 Node.js를 설치한 뒤, 프로젝트 폴더의 `Start-Rug.cmd`를 실행해 주세요. 처음 실행할 때 필요한 패키지를 설치합니다.

터미널에서 실행하려면 다음 명령어를 사용하시면 됩니다.

```bash
npm ci
npm start
```

브라우저에서 먼저 살펴보고 싶다면 함께 제공되는 데모 HTML을 열어보세요. 데모에서는 Windows 바탕화면 연결과 모니터 선택 기능을 사용할 수 없습니다.

## 조작 방법

| 조작 | 기능 |
| --- | --- |
| 러그 위에서 좌클릭 드래그 | 러그 잡아 옮기기 |
| 러그 위에서 우클릭 드래그 | 러그 베기 |
| Ctrl을 먼저 누른 뒤 드래그 | 러그 바깥에서부터 베기 시작 |
| Ctrl + 마우스 휠 | 러그 크기 변경 |
| Ctrl + Shift + 마우스 휠 | 검술 변경 |
| Ctrl + Shift + R | 바탕화면에서 러그 원위치 |
| Shift만 누르기 | 러그 아래로 마우스 입력 통과 |

트레이 아이콘에서 환경설정을 열거나 앱을 종료할 수 있습니다.

## 내 이미지로 바꾸기

환경설정의 **러그 디자인 → 이미지 변경**에서 파일을 선택해 주세요.

PNG와 WebP를 지원하며 파일 크기는 최대 16MB입니다. 투명 배경을 가진 이미지를 사용하면 캐릭터나 물체의 윤곽을 살릴 수 있습니다. 이미지 비율은 유지되며, 앱에서 사용할 크기로 조정됩니다.

러그 선택 목록의 여섯 번째 항목을 고르면 기존 러그로 돌아갈 수 있습니다.

## 크기와 화면 배치

러그 크기는 60~300%, 검기 크기는 25~150% 범위에서 조절할 수 있습니다. 러그 100%의 기준은 1080×675 앱 좌표이며, Windows 디스플레이 배율에 따라 실제 화면에서 차지하는 픽셀 수는 달라질 수 있습니다.

**최하위**는 바탕화면에서 사용하는 배치이고, **최상위**는 다른 창 위에 러그를 표시하는 배치입니다. 최상위에서 크게 펼치면 화면을 가리는 용도로도 사용할 수 있습니다.

모니터를 바꾸면 해당 화면으로 이동하면서 러그가 원위치됩니다. 선택한 모니터의 연결이 끊기면 주 모니터로 돌아갑니다.

## Windows 빌드

프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
npm run package:win
```

빌드가 끝나면 `dist/win-unpacked/HyeonbitRug.exe`에서 실행할 수 있습니다.

소스를 수정해도 이전에 빌드한 실행 파일은 바뀌지 않습니다. 변경 내용을 실행 파일에 반영하려면 다시 빌드해 주세요.

## 업데이트할 때

먼저 트레이에서 앱을 완전히 종료해 주세요. 전체 소스는 새 폴더에 풀어서 실행하는 것을 권장합니다.

수정 파일만 받은 경우에는 안내된 파일을 프로젝트 폴더에 덮어써 주세요. 기존 소스를 업데이트한 뒤 `Start-Rug.cmd`로 실행하면, 확인된 옛 파일만 정리합니다. 사용자가 수정한 파일은 그대로 둡니다.

## 참고한 프로젝트

- [under-the-rug](https://github.com/siliconbag/under-the-rug)
- [PixelFX](https://github.com/patch-gg/pixelfx)

러그 구현과 이펙트를 만드는 과정에서 참고한 프로젝트입니다. 원본 소스의 라이선스와 저작권 고지는 `LICENSE` 및 `licenses` 폴더에 남겨두었습니다.

현재 사용되는 검술 이미지는 별도로 제작·가공한 이미지이며, PixelFX 원본 이미지와는 구분됩니다. 일부 이미지 제작에는 AI를 사용했습니다.

귀멸의 칼날을 소재로 만든 비공식 팬 프로젝트입니다. 원작 캐릭터와 작품에 관한 권리는 각 권리자에게 있습니다. 소스 라이선스가 캐릭터나 이미지에 대한 권리까지 포함하는 것은 아닙니다.
